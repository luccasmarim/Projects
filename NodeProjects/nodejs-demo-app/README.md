# Node.js Demo Application

This project is a demonstration of the capabilities of Node.js, showcasing various features such as handling HTTP requests, file operations, and utility functions.

## Features

- HTTP server to handle requests and responses
- Utility functions for data processing and logging
- Modular structure for easy maintenance and scalability

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd nodejs-demo-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the application, run the following command:
```
npm start
```

The application will start an HTTP server on port 3000. You can access it by navigating to `http://localhost:3000` in your web browser.

### Usage

The application demonstrates various Node.js capabilities. You can explore the `src/index.js` file to see how HTTP requests are handled and how utility functions from `src/utils/helper.js` are utilized.
